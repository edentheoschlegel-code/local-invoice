# Local Invoice

Create professional invoices and estimates as PDFs — clients, dashboard insights, and backups, all stored on your device.

**Live:** [localinvoiceapp.com](https://localinvoiceapp.com)

## Highlights
- 100% on-device: invoice and client data never leaves the browser
- Offline-first PWA — fully functional without a connection once loaded
- Strict Content Security Policy; client-side PDF generation with multi-page pagination
- One-time Pro (logo and custom branding) via Stripe + RevenueCat Web Billing

## Tech notes
Vanilla JavaScript PWA served as a static site (GitHub Pages). Data persists in local browser storage with export/restore.

## Run locally
Serve the folder with any static file server, e.g. `npx serve .`
